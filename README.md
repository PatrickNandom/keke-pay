**Keke-Pay: Tricycle Revenue Management App**
**Overview**
Keke-Pay is a backend solution designed to simplify the management of daily dues for tricycle drivers.
It automates the payment process using digital wallets and ensures timely deductions, improving the 
financial management and compliance for drivers and regulatory bodies.

**Key Features**
Automated Deductions: Daily dues are deducted automatically from the drivers' digital wallets.
Enforcer Verification: Simplifies the process of verifying payments in real-time.
**Tech Stack**
Backend: Node.js, Express
Database: MongoDB
Mobile App: Flutter (Frontend)
Payment Integration: Payment Gateway API
